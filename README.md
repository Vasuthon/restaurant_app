# HOTPOT MAN — Buffet POS System

ระบบสั่งอาหารผ่าน QR Code สำหรับร้านชาบูบุฟเฟต์ ลูกค้าสแกน QR ที่โต๊ะแล้วสั่งอาหารจากมือถือตัวเองได้เลย ไม่ต้องเรียกพนักงานมาจด ออเดอร์วิ่งเข้าจอครัวแบบเรียลไทม์

ระบบแบ่งเป็น 2 หน้าหลัก:

- **หน้าบ้าน** ([index.php](index.php)) — หน้าที่ลูกค้าใช้: ดูเมนู สั่งอาหาร เรียกพนักงาน (เติมน้ำซุป/เก็บถาด/เช็คบิล) ดูสถานะออเดอร์ และดูบิล
- **หลังบ้าน** ([staff.php](staff.php)) — หน้าที่ร้านใช้ (ป้องกันด้วย PIN): แดชบอร์ดภาพรวม, จัดการโต๊ะ, จอครัว (KDS), จัดการเมนู/สต็อก/หมวดหมู่

> **เว็บจริงรันอยู่บน Docker เท่านั้น** ไม่ต้องติดตั้ง PHP/MySQL/Apache เองบนเครื่อง

## Tech Stack

- PHP 8 + Apache — API แบบไฟล์เดี่ยวต่อ endpoint อยู่ใน [api/](api)
- MySQL 8.0
- Vue 3 + Tailwind CSS (โหลดผ่าน CDN ไม่มีขั้นตอน build ใดๆ แก้ไฟล์แล้ว refresh เห็นผลทันที)
- Docker Compose — รันทั้งระบบด้วยคำสั่งเดียว (เว็บ + ฐานข้อมูล + phpMyAdmin)

## เริ่มต้นใช้งาน (3 ขั้นตอน)

### สิ่งที่ต้องมี

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (มี Docker Compose มาให้แล้ว)

### ขั้นตอน

**1. ตั้งค่าเริ่มต้น (ทำครั้งเดียว)**

คัดลอกไฟล์ตัวอย่าง env แล้วแก้ค่าตามต้องการ:

```bash
cp .env.example .env
```

| ตัวแปร | ความหมาย |
|---|---|
| `DB_ROOT_PASSWORD` | รหัสผ่าน root ของ MySQL |
| `DB_NAME` | ชื่อฐานข้อมูล |
| `DB_USER` / `DB_PASSWORD` | ผู้ใช้ฐานข้อมูลที่แอปใช้เชื่อมต่อ |
| `STAFF_PIN` | PIN สำหรับเข้าหน้าพนักงาน/ครัว ([staff.php](staff.php)) |

**2. สั่งรัน**

Windows (PowerShell) แนะนำให้ใช้สคริปต์นี้แทนคำสั่ง `docker compose up` ตรงๆ:

```powershell
.\docker-up.ps1 -d
```

สคริปต์นี้จะตรวจ IP วงแลน (Wi-Fi/เครือข่าย) ของเครื่องอัตโนมัติก่อนเปิดระบบ เพื่อให้ QR Code ที่โต๊ะใช้งานได้จากมือถือลูกค้าทันที (ดูหัวข้อ [ให้ลูกค้าสแกน QR จากมือถือจริง](#ให้ลูกค้าสแกน-qr-จากมือถือจริง) ด้านล่าง) ถ้าไม่ใช้ Windows หรือไม่สนใจฟีเจอร์ QR วงแลน ใช้คำสั่งปกติได้เช่นกัน:

```bash
docker compose up -d --build
```

ครั้งแรกที่รัน MySQL จะสร้างฐานข้อมูลและ import [schema.sql](schema.sql) ให้อัตโนมัติ (มีข้อมูลตัวอย่าง: โต๊ะ 25 โต๊ะ, เมนูกว่า 150 รายการ)

**3. เข้าใช้งาน**

- หน้าลูกค้า: <http://localhost:8080>
- หน้าพนักงาน/ครัว: <http://localhost:8080/staff.php>
- phpMyAdmin (ดู/แก้ฐานข้อมูลด้วยตา): <http://localhost:8081> — ล็อกอินด้วย `DB_USER`/`DB_PASSWORD` (หรือ `root`/`DB_ROOT_PASSWORD` สำหรับสิทธิ์เต็ม) จาก `.env`

### หยุด / ล้างระบบ

```bash
docker compose down
```

คำสั่งนี้ **ไม่ลบข้อมูลในฐานข้อมูล** เพราะข้อมูลถูกเก็บไว้ใน Docker volume (`db_data`) แยกต่างหาก ครั้งต่อไปที่เปิดใหม่ ข้อมูลเดิมจะยังอยู่ครบ

หากต้องการล้างข้อมูลฐานข้อมูลทั้งหมดเพื่อเริ่มใหม่ (โต๊ะ, ออเดอร์, ทุกอย่างกลับไปเป็นค่าเริ่มต้นใน `schema.sql`):

```bash
docker compose down -v
```

## วิธีใช้งานระบบ

1. เข้า [staff.php](staff.php) แล้วใส่ PIN (`STAFF_PIN` ใน `.env`) เพื่อเข้าสู่ระบบพนักงาน
2. ไปแท็บ **ผังโต๊ะทั้งหมด** กด **เปิดโต๊ะใหม่** เลือกแพ็กเกจ/จำนวนคน ระบบสร้าง QR Code ประจำโต๊ะให้อัตโนมัติ
3. ให้ลูกค้าสแกน QR Code ที่โต๊ะ (หรือกด "เปิดดูหน้ามือถือลูกค้า" เพื่อดูตัวอย่างเองในแท็บใหม่) จะเข้าสู่หน้าสั่งอาหารของโต๊ะนั้นโดยตรง
4. ลูกค้าเลือกเมนู กดสั่ง (มี popup ให้ยืนยันก่อนส่งเข้าครัวกันกดพลาด) → ออเดอร์เข้าคิวที่แท็บ **ครัว KDS** ทันที
5. ครัวกดเปลี่ยนสถานะ "กำลังปรุง" → "เสิร์ฟแล้ว" ถ้าวัตถุดิบหมดกลางคัน กดปุ่ม "หมด" ที่ตัวเมนูในออเดอร์ได้เลย ระบบจะแจ้งเตือนไปยังทุกโต๊ะที่สั่งรายการนั้นค้างอยู่ทันที
6. ลูกค้ากดเรียกพนักงานได้จากมือถือ (เติมน้ำซุป / เก็บถาด / เช็คบิล) — ฝั่งครัวเห็นเฉพาะคำเรียกเติมน้ำซุป ฝั่งพนักงานเห็นเฉพาะเช็คบิล/เก็บถาด ไม่ปนกัน พร้อมเสียงแจ้งเตือนเมื่อมีคำเรียกใหม่
7. เมื่อลูกค้าทานเสร็จ พนักงานกด **เช็คบิล** ที่การ์ดโต๊ะ ระบบคำนวณยอดอัตโนมัติ พิมพ์ใบเสร็จได้ (มี QR ตัวอย่างสำหรับสแกนจ่ายเงิน — เป็นแค่ตัวอย่างเฉยๆ ไม่ใช่ QR รับเงินจริง) แล้วกดปิดโต๊ะ

### ให้ลูกค้าสแกน QR จากมือถือจริง

เครื่องที่รัน Docker กับมือถือลูกค้าต้อง **ต่อ Wi-Fi/เครือข่ายเดียวกัน** ถ้าเปิดระบบด้วย `.\docker-up.ps1` ตามขั้นตอนข้างต้น ลิงก์และ QR Code ทุกอันจะใช้ IP วงแลนที่ตรวจได้อัตโนมัติอยู่แล้ว ไม่ต้องตั้งค่าเพิ่ม

ถ้า IP ของเครื่องเปลี่ยน (เช่น รีสตาร์ท router) แค่รัน `.\docker-up.ps1 -d` ใหม่อีกรอบ ลิงก์/QR จะอัปเดตตาม IP ใหม่ให้อัตโนมัติ — หน้าแดชบอร์ดพนักงานก็มีกล่องแสดงลิงก์สำหรับแชร์ให้ลูกค้าพร้อมปุ่มคัดลอกด้วยเช่นกัน

## ฟีเจอร์หลัก

**ฝั่งลูกค้า**
- ดูเมนูแบ่งตามหมวดหมู่ ค้นหา/กรองได้ พร้อมล็อกเมนูที่ต้องอัปเกรดแพ็กเกจ
- ตะกร้า + ยืนยันก่อนส่งออเดอร์เข้าครัว (กันกดพลาด)
- ติดตามสถานะออเดอร์แบบเรียลไทม์ รวมถึงแจ้งเตือนถ้าเมนูที่สั่งไปหมดกลางคัน
- เรียกพนักงาน (เติมน้ำซุป / เก็บถาด / เช็คบิล) พร้อมยืนยันก่อนกดทุกครั้ง
- ดูสรุปยอดบิลได้เอง

**ฝั่งพนักงาน/ครัว**
- แดชบอร์ดภาพรวมยอดขาย จำนวนโต๊ะที่ใช้งาน ออเดอร์ค้าง
- จัดการโต๊ะครบวงจร: เปิด/ปิดโต๊ะ, แก้ไขจำนวนคน, เพิ่ม/ลบ/เปลี่ยนชื่อ/ปิดใช้งานชั่วคราวได้ (กันลบโต๊ะที่มีประวัติการใช้งานอยู่)
- จอครัว (KDS) แสดงเฉพาะออเดอร์ของโต๊ะที่ยังเปิดอยู่ (ไม่มีของเก่าจากโต๊ะที่ปิดบิลไปแล้วมาปนให้รก) พร้อมปุ่มแจ้ง "ของหมด" ด่วนต่อรายการ
- จัดการเมนู/สต็อก/หมวดหมู่ได้ครบ (เพิ่ม/แก้ไข/ลบ/เปิดปิดพร้อมขาย) พร้อมอัปโหลดรูปเมนูได้
- เสียงแจ้งเตือนอัตโนมัติเมื่อมีออเดอร์ใหม่หรือลูกค้าเรียกพนักงาน
- พิมพ์ใบเสร็จพร้อม QR ตัวอย่างสำหรับสแกนจ่ายเงิน

## โครงสร้างโปรเจกต์

```
index.php          หน้าลูกค้า (หน้าบ้าน)
staff.php          หน้าพนักงาน/ครัว (หลังบ้าน, ต้องใส่ PIN)
api/               API endpoints (PHP, ไฟล์ละ 1 endpoint)
config/            การเชื่อมต่อฐานข้อมูล (db.php) และตรวจสอบสิทธิ์พนักงาน (auth.php)
partials/head.php  ส่วน <head> ที่ใช้ร่วมกันทั้งสองหน้า
assets/shared.js   ฟังก์ชัน JS ที่ใช้ร่วมกันทั้งสองหน้า
uploads/menu/      รูปเมนูที่อัปโหลดจากหน้าจัดการสต็อก
schema.sql         โครงสร้างตารางฐานข้อมูล + ข้อมูลตัวอย่าง (seed)
docker-compose.yml นิยาม 3 service: web (แอป), db (MySQL), phpmyadmin
docker-up.ps1      สคริปต์เปิดระบบ ที่ตรวจ IP วงแลนให้อัตโนมัติก่อนสั่ง docker compose up
```

## หมายเหตุด้านความปลอดภัย

ค่าเริ่มต้นใน `.env.example` เป็นค่าใช้สำหรับพัฒนา/สาธิตเท่านั้น หากจะนำไปใช้งานจริงต้องเปลี่ยนรหัสผ่านและ `STAFF_PIN` ทั้งหมด และไม่ควร commit ไฟล์ `.env` จริงขึ้น git
